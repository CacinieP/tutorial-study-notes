# 各 Phase 可直接复制的 Prompt 模板

把 `【主题】` 替换为实际主题，按顺序喂给 Agent。每段 prompt 对应 SKILL.md 的一个 Phase。

---

## Phase 1 · 五视角扫描

```
我想学【主题】。请分别以这 5 个视角的立场，说明各自会怎么看待这个主题、各自的核心依据是什么：
1. 天天上手干活的实践者——什么 actually 能用、什么只是论文里好看
2. 读遍论文的学者——理论边界，结论成立的严格前提
3. 觉得主流方向全错了的怀疑者——共识的漏洞
4. 盯着钱往哪流的经济学家——用激励结构解释行为，不看宣传看利益
5. 见过类似剧情怎么收场的历史学家——认模式：这事以前发生过，结局长什么样
每个观点注明来源和可信度；不确定的内容标注「凭记忆未核」。
```

## Phase 2 · 矛盾图

```
基于刚才的 5 个视角，画一张矛盾图，回答 5 问：
1. 哪些视角在直接冲突？各自的依据分别是什么
2. 谁的证据最强、谁的最弱？为什么
3. 哪一个问题一旦有答案，就能化解最大的矛盾
4. 所有视角都同意的是什么（共识区）
5. 没有任何视角提到的是什么（盲区）
```

## Phase 3 · 调研简报

```
把 5 个视角和矛盾图综合成一份调研简报，5 要素缺一不可：
1. 一段话总结（讲给只有 60 秒的 CEO 听，要细节，不要标题党）
2. 按可靠性排序，标注哪些视角支持、哪些反对
3. 隐藏关联：两个看似无关的观点，背后是不是同一件事
4. 一条具体的行动建议（以我的角色：【我的角色】，我该做什么不一样的事）
5. 一个前沿问题（它的答案会改变我们对这个主题的全部理解）
```

## Phase 4 · 同行评审

```
对刚才这份简报做一次同行评审：
1. 给 5 个关键发现逐个打 1-10 的可靠性分，并解释理由
2. 最没把握的是哪个结论？需要什么信息才能验证它
3. 哪个视角在综合时占的比重过大了
4. 有没有第 6 个视角是该加进来、加了会改变结论的
5. 如果一位教授来评审这份简报，会打几分，会让我改什么
评审发现的问题请直接改写出修订版简报。
```

## Phase 5 · 资源筛选 + 一周路径

```
关于【主题】，选出 5 个最值得用的资源（书、视频、课程、社区都行），每个说清楚：
1. 它为什么比同类强
2. 该怎么用（读/看/练）
3. 大概要花多久
4. 我该从它身上拿走的一个关键点
再告诉我哪些是被高估的、我该躲开的坑（负面清单）。
最后把这 5 个排成一条一周能走完的学习路径，注明每天做什么、预计耗时。
```

## Phase 6 · 五级难度 × 8 问

```
关于【主题】，给我 5 个清晰的难度级别（完全初学者/基本理解/实际使用者/问题解决者/自信的实践者），
每个级别回答 8 问：
1. 级别名称 2. 阶段理解 3. 阶段「掌握」是什么样子
4. 最需要重点关注的概念或技能 5. 进阶里程碑
6. 动手练习或小型项目 7. 可能常犯的错误 8. 简单自测问题
解释保持实用、对初学者友好，专注于真正的进步。
```

## Phase 7 · 80/20 + 10 次课

```
我想用 2 个小时学【主题】。请先找出能带来 80% 实际效果的那 20% 的概念和技能，
解释它们为什么是核心；然后排成 10 次课的学习计划，每次课包含：
学习目标、关键概念、一个动手练习、一个推荐资源。
```
